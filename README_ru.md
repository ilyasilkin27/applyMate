# ApplyMate

ApplyMate - это веб-приложение, которое поможет вам упростить процесс подачи заявок на работу. Оно позволяет:

- Войти в систему, используя учетные данные hh.ru.
- Получить все ваши резюме и рекомендованные вакансии.
- Подать заявку на все вакансии одним щелчком мыши.
- Искать вакансии по ключевому слову, чтобы найти наиболее подходящие предложения.

Обратите внимание, что существует ограничение на 200 вакансий в день, на которые вы можете подать заявку.
