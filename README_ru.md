# ApplyMate

**ApplyMate** — это веб-приложение, которое делает процесс подачи заявок на работу проще и быстрее.  

- Войти через свою учетку hh.ru.
- Просмотреть все свои резюме и вакансии.
- Подать заявку на все вакансии в один клик.
- Искать вакансии по ключевым словам.

**Ограничение:** 200 заявок в день.
